# Sistema de Login com FastAPI e SQLite

Projeto de autenticação de usuários desenvolvido em Python utilizando FastAPI, SQLite e Bcrypt.

O sistema realiza cadastro, login, atualização e exclusão de usuários, utilizando criptografia de senhas para maior segurança.

---

## Tecnologias Utilizadas

- Python
- FastAPI
- SQLite3
- Pydantic
- Bcrypt
- Uvicorn

---

## Funcionalidades

 Cadastro de usuários  
 Login com autenticação  
 Criptografia de senha com Bcrypt  
 Atualização de usuários  
 Exclusão de usuários  
 API REST  
 Integração com banco SQLite
